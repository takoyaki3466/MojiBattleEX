# Combat object images

Generated with the built-in OpenAI image generation tool. `combat-objects-sheet.png` is the retained 2×2 source; the four cropped runtime assets are `falling-building.png`, `meteor.png`, `healing-core.png`, and `energy-lance.png`.

Final prompt:

> Transparent exact 2×2 game-object sprite sheet: a diagonally tilted collapsing glass skyscraper, a huge flaming meteor, a cyan-white healing core with crystalline heart, and a golden-blue horizontal energy lance. Polished anime arcade fighting-game VFX, strong motion and emissive light, one isolated object per quadrant, no text, logo, watermark, grid, or opaque backdrop.

The built-in editor was then asked to remove only the background and preserve the four objects and their glow edges. The resulting PNG alpha channel was checked before cropping.

`d-racing-car.png` was generated in stylized-concept mode as a transparent 2D combat sprite. Prompt summary: an exaggerated compact racing car in three-quarter side view, charging left-to-right, neon green/cyan/white/gold, oversized wheels, bright headlights, tightly integrated arcade-anime speed streaks and electric sparks, high-contrast silhouette, with no driver, text, logo, watermark, ground, or shadow.

`falling-unit.png` was generated with the built-in image tool in stylized-concept mode. Final prompt: one enormous heavy three-dimensional Japanese word made of the exact kanji `単位`, falling diagonally like a meteor; cracked stone-and-gold surfaces, cyan and magenta impact energy, sparks, debris, arcade-anime VFX, high contrast and thick outline; isolated on a genuinely transparent background with no other text, logo, watermark, ground, or frame.
