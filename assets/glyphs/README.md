# Glyph assets

PNG群は、ローカル環境にインストールされている Noto Sans JP からラスタライズした透明背景の専用グリフです。フォントファイル自体は同梱していません。正式配布時には、フォントの利用条件と生成物の扱いを改めて確認してください。

`kabushiki.png` はキャラクター板、`stock.png`, `formula.png`, `company.png`, `society.png` は4発の弾に使用されます。いずれも3D空間内の板モデルへ貼られ、位置・向き・スケール・独立した当たり判定を持ちます。

`a.png` は同梱の Noto Sans JP から決定的にラスタライズした透過PNGで、A本体、全方位スキル、召喚家族の表示に共用されます。白い太字に濃緑の縁を付けています。
