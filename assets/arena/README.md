# Arena assets

The arena uses two CC0 assets downloaded from Poly Haven's official distribution server on 2026-10-11.

- `sparse-grass.jpg`: 1K diffuse map from **Sparse Grass**, by Amal Kumar. Source: https://polyhaven.com/a/sparse_grass
- `hilly-terrain.jpg`: tonemapped panorama from **Hilly Terrain 01**, by Sergej Majboroda. Source: https://polyhaven.com/a/hilly_terrain_01

Both source pages identify the assets as CC0. Poly Haven license: https://polyhaven.com/license

The grass texture is tiled across the arena floor. The landscape panorama is placed on four distant, double-sided scenery panels around the playable area.
